AEM Integration Guide: How to use this in Adobe Experience Manager

Is page ka code pure Vanilla JavaScript aur responsive SVG me likha gaya hai. Isko aap AEM me 2 aasan tareeqon se use kar sakte hain:

Tareeqa 1: AEM Embed Component (Quickest)

AEM page editor me Embed / Raw HTML Component drag & drop karein. Is page ke relevant chart ka HTML container aur script block copy karke paste kar dein. Direct client-side API fetch se chart aur SEO metadata dono turant chal jayenge.

Tareeqa 2: Custom AEM Component + Clientlib

1. HTL template (chart.html) me SVG container div banayein.
2. CSS ko component ki clientlib-site/css me dalein.
3. JS fetch logic ko clientlib-site/js me dalein.
AEM dialog me API endpoint ka authorable field bhi de sakte hain.

Tareeqa 3: SEO Metadata in <head>

Script automatic dynamic <script type="application/ld+json"> inject karti hai. Google Search bot modern client-side JSON-LD ko poori tarah index karta hai. "View Live JSON-LD" button se aap inspect kar sakte hain.
